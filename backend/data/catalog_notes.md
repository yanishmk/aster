# Aster Product Catalog Notes

## Retailers

Start with:

- Amazon Associates
- Sephora Affiliates via Rakuten/Skimlinks, depending on approval and country

## Important

`affiliate_url` must be replaced with your real affiliate links before launch.

For Amazon, do not copy Amazon product images manually unless your Associates/API setup allows it.
Use the Product Advertising API or approved image assets.

For Sephora, use affiliate network product feeds or approved creative assets when available.

The current `image_url` values are placeholders so the UI can be developed safely.
